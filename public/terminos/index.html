El servicio

CeBe Pilot es un asistente de inteligencia artificial que genera textos, código y diseños a partir de lo que escribís. Funciona con modelos Claude de Anthropic.

Las respuestas pueden equivocarse

La inteligencia artificial puede dar información incorrecta o desactualizada. Verificá lo importante. CeBe Pilot no reemplaza asesoría médica, legal, financiera ni profesional.

Uso aceptable

  • No uses CeBe Pilot para actividades ilegales, para dañar a otras personas, para crear spam o para intentar saltarte sus límites.
  • No intentes sobrecargar el servicio ni acceder a partes privadas.
  • Podemos limitar o bloquear el acceso ante un uso abusivo.

Lo que generás

Podés usar los textos, el código y los diseños que obtengas, bajo tu responsabilidad. Revisalos antes de publicarlos, sobre todo si incluyen marcas, imágenes o datos de terceros.

Planes y códigos de acceso

  • El plan Gratis tiene un límite de mensajes por día. Los planes Pro y Max se activan con un código personal que recibís al confirmar el pago, con la vigencia indicada al comprarlo.
  • El código es para tu uso: no lo compartas ni lo publiques. Un código compartido puede desactivarse.
  • Las condiciones de pago y de reembolso se informan al momento de comprar el plan.

Disponibilidad

Hacemos lo posible por mantener CeBe Pilot disponible, pero puede pausarse por mantenimiento, por fallas del proveedor o al llegar a los límites de uso del mes.

Recomendaciones

Cuando necesitás una página web profesional, CeBe Pilot puede recomendarte a CeBe Studio, un estudio aliado. Contratar o no sus servicios es decisión tuya y se rige por las condiciones de ese estudio.
